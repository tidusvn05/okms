# P008-MS01 · Portable contracts

## Intent

Extend the portable catalog with review, clarify behavior-preserving refactoring under implementation, and supply optional role, delegation, and worker-result formats for the current spec.

## Constraints

- Always: retain the four-section micro spec, sequential outcomes, one progress owner, truthful evidence, legacy history, and identical shared files across both profiles.
- Never: imply native agent registration or permission enforcement, delegate without applicable authorization, or let worker reports close the parent contract.

## Acceptance

- The catalog selects review for findings and implementation for structural improvement with retained behavior; review scope, location/impact/evidence, no-findings limits, and refactor verification are explicit.
- Optional roles, briefs, and results distinguish reusable instructions, a bounded assignment, and observed evidence. The coordinator owns shared updates, acceptance, integration, and saved recovery.
- Ordinary tasks load no optional agent documents. Both profiles include self-contained copies and retain adoption, Goal, and historical contracts.

## Verify

- Method: review routing boundaries and coordinator failure cases, compare shared payload bytes and links, and run the document checker with its updated inventory.
- Expected: consistent optional contracts, preserved existing behavior, and structurally valid copies.
- Tests: existing contract tests and focused new structural guard tests cover inventory, sections, and progress ownership; behavioral agent pilots follow after the examples and runner are ready.
