# P014-MS06 · Verified regular Rust release

## Intent

Complete the authorized final spike and publish standalone Rust Hybrid Team 0.2.0 together with the merged portable 0.4.1 source changes.

## Constraints

- Always: freeze source/binary provenance, retain failed/partial evidence, and distinguish real native observations from fixtures and platform smoke tests.
- Always: preserve project staging/HEAD/docs, required gates, exact native IDs, previous assets and deliberate-upgrade boundaries.
- Never: weaken criteria, silently restart partial work, override models/logins, enable untrusted hooks, bypass permissions, or publish before required acceptance.

## Acceptance

- Download checked Actions artifacts for the final embedded payload. Binary drift rejects reuse; saved evidence remains gradable without executing a current binary.
- Final native Codex/Claude coordinator cases each return both providers, acknowledged peer replies, exact-session resume, handoff, real integration/root checks and independent behavior passes. The unavailable-gate case preserves failed verification and incomplete rows without applying candidates.
- Report exact versions/source/binary hashes, retained attempts, actual results and activation limits; ordinary maintenance/CI checks pass.
- A matching new tag publishes a regular latest release. Public assets match checked downloads, Python-free pinned/default installation succeeds, the published binary matches the observed one, and 0.1.0 remains immutable.

## Verify

- Method: provenance/grader controls, four-platform Actions rehearsal, the real three-case native runner, independent root oracle, maintainer/Rust checks, observed tag workflow and public download/install/hash inspection.
- Expected: all necessary criteria supported by final-payload evidence and actual release state; absent native/platform activation remains explicitly unclaimed.
