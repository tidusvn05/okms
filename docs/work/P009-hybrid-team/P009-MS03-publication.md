# P009-MS03 · Publish Hybrid Team

## Intent

Make the optional runtime profile discoverable and reviewable without changing portable-profile adoption or promising unobserved native activation.

## Constraints

- Always: preserve Lite/Plan-first 0.4.0 contracts, illustrate examples honestly, and distinguish structural checks from live observations.
- Always: keep runtime internals in code and operator details in the guide; actual project checks remain project-owned.
- Never: launch a provider in ordinary maintainer checks or overwrite existing setup/configuration through a portable setup prompt.

## Acceptance

- README offers profile selection, a complete preserving Hybrid Team setup prompt, and local setup commands with prerequisites/trust boundaries.
- Maintainer guidance/checks cover the new payload, roles, skills, native configuration, and retained portable contracts.
- An illustrative walkthrough explains coordinator ownership, peer messaging, isolated integration, and incomplete verification.
- An opt-in pilot runner prepares disposable projects, captures actual native IDs/results/streams, and grades observable invariants without inferring success from requests.

## Verify

- Method: required document/unit checks, fixture-only runner, independent grader scenarios, and diff review.
- Expected: existing contracts and new payload pass; ordinary checks start no provider session.
- Tests: live execution and observed reports belong to the next saved pilot contract.
