# Working on okms

okms distributes portable Markdown workflows for coding agents. Its templates require no runtime, installer, or agent-specific integration.

- Write all repository documentation, templates, examples, and code comments in English.
- Keep Lite and Plan-first payloads self-contained after copying.
- Keep implementation details in code and retain only essential behavioral constraints in micro specs.
- Preserve existing project documents and agent instructions during adoption.
- Examples are illustrative; never report their verification commands as executed against an application.
- Check the repository with `.venv/bin/python scripts/check_docs.py`; see CONTRIBUTING.md for the maintainer environment and review scenarios.

For substantive project tasks, read and follow [the workflow](docs/workflow.md), starting with [the docs index](docs/index.md).
