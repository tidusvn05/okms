# Coordinate Hybrid Team work

Read `.okms/team.json` to locate the installed workflow and context. Use the role/identity from the lifecycle hook; a missing hook needs native trust/loading review or an explicit join. Standby and worker identities cannot perform coordinator operations.

Save the plan and selected micro specs before dispatch. Assign ready independent scopes with actual checks as argument arrays. Use both providers when useful; a single write scope can pair with cross-review. Do not create work merely to consume a worker slot.

Use `python3 .okms/team.py COMMAND --identity IDENTITY_FILE --input -` with JSON stdin. Read the installed `team.md` only for the operation needed. Review returned diffs, real evidence, and gaps; integrate and verify the actual root before checkpointing done. The plan owns task progress; runtime events own operational observations.

Preserve project instructions, original edits, staging, artifacts, session IDs, and consumed time. Native trust/permission denial remains incomplete. Transfer or recover ownership explicitly; never bypass it, use a latest-session shortcut, or silently retry partial execution.
